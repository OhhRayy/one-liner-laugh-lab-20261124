## What it does

`main.py` writes one funny line to `/output/entry.txt`: the excuse a robot vacuum gives after eating a sock. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> I didn't eat your sock; I adopted it. It lives under the couch now and, frankly, it's thriving.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
